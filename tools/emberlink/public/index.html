EmberLink

Share a message that can only be viewed once. Encrypted in your browser.

How to use
Write your message, optionally set a password and expiration, then click Create Link. The link contains the decryption key after the # symbol — keep it private.

Limitations
• Images must be smaller than 500KB
• Message is encrypted in your browser before being sent
• After the maximum views are reached, the message is permanently deleted
• Preview bots (Slack, Discord, etc.) will not consume a view
