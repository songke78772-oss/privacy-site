Burn Chat

Temporary group chat. Messages disappear when the room ends.

100% Temporary

All messages are permanently deleted when the room expires or is dissolved.

Recommended: Use CipherDeck on this site to send the password securely.

1. Set room options
Choose participants, duration, and your display name.

2. Create the room
Click Create Room. Share the one-time invite links only with people you trust.

3. Chat
Everyone joins with a link. Messages disappear when the room ends.

4. Optional encryption
Enable Deep Encryption and set a short password. Only people with the password can read messages.

Rooms are temporary. When the timer ends or the creator dissolves the room, all messages are permanently deleted.

Invite links work only while the room exists. After it expires, they become invalid.

Deep Encryption is client-side. If you lose the password, messages cannot be recovered.

Nothing is stored after the room ends.
